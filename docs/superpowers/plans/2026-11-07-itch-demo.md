# Offline browser demo implementation plan

Goal: export the existing life-live viewer as an offline seed-4 replay for itch.io.

Architecture: embed a compact deterministic recording, vendored Three.js, existing shaders and creature builder. A small replay transport replaces HTTP/SSE only in exported mode; the normal local live viewer retains its behavior. Add explicit orbit/surface/creature camera buttons, responsive hints and credit. Browser playback interpolates creature positions using the existing animation loop; Python/circuits run at export time only.

Constraints: local checkout only; PYTHONPATH includes /workspace/NIM; no push or publication; do not commit generated packages; index.html at zip root; below 50 MB and 1000 files; no network/backend at runtime.

1. Write exporter packaging tests and Node replay-control assertions; run red before implementation.
2. Implement replay transport, conditional viewer hookup, camera controls and exporter. Record seed 4 from LiveSim with planted life and QWRK circuit mind, rejecting circuit failures.
3. Run unit/regression tests. Serve exported directory on an ephemeral local HTTP port; use Chromium to verify sandboxed iframe, pause, scrub, looping, resize, camera modes and photo toggle. Save four screenshots and console/request report, stop owned server.
4. Document reproduction and limitations in README. Inspect staged diff and locally commit only source, tests and docs on main; never push.
